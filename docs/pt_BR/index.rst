moodle-tool_competencycustomfields
==================================

**Campos personalizados para competências e quadros de competências: gerencie como os campos personalizados do curso, edite os valores a partir das páginas de competências e leia-os em integrações.**

.. figure:: img/display.png
   :alt: Página de edição de uma competência com os valores dos campos personalizados e o botão Edit custom fields acima do formulário.
   :width: 100%

   Os valores de uma competência, com o link para editá-los.

* **Campos onde o Moodle não tem.** O Moodle tem campos personalizados para cursos, coortes e grupos, mas não para competências. Esta ferramenta acrescenta duas áreas: competências e quadros de competências.
* **Todos os tipos de campo.** Texto, área de texto, menu, caixa de seleção, data e qualquer outro tipo instalado no site, com as configurações de sempre.
* **Controle de quem vê cada valor.** Cada campo é visível para todos, só para quem pode editar os valores ou para ninguém.
* **Pronto para integrações.** O web service ``local_fieldssuite_get_values`` devolve os valores que o usuário pode ver.

Faz parte da `Moodle Fields Suite <https://moodle-fields-suite.github.io>`_; requer o `local_fieldssuite <https://moodle-fields-suite.github.io/local_fieldssuite/>`_.
